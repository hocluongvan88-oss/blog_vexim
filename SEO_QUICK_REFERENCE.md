### 2. Meta Description - NOW OPTIMIZED
When creating blog posts, write descriptions like this:

**✅ GOOD:**
```
"Hướng dẫn đăng ký FDA bước 1 đến bước 10 - Quy trình chi tiết với tài liệu bắt buộc - Vexim Global"
```
- Length: ~140 characters ✓
- Includes main keyword: FDA ✓
- Shows unique angle: "bước 1 đến bước 10" ✓
- Ends with brand: Vexim Global ✓

**❌ AVOID:**
```
"Bài viết này nói về quá trình đăng ký FDA tại Hoa Kỳ cho các công ty xuất khẩu thực phẩm từ Việt Nam"
```
- Too long (160+ chars) ✗
- Vague opening "Bài viết này nói về" ✗
- No brand mention ✗

## 📝 Blog Post Checklist

When creating a new blog post, verify:

### SEO Checklist
- [ ] **Title** - 50-60 characters, includes main keyword
- [ ] **Meta Description** - 140-160 characters, unique, actionable
- [ ] **Tags** - 3-5 related keywords (e.g., "FDA, Export, Compliance")
- [ ] **Category** - One of: FDA, GACC, MFDS, Truy xuất, Tin tức, Xuất nhập, Pháp lý
- [ ] **Featured Image** - At least 1200x630px, relevant to topic
- [ ] **Content** - 800+ words, includes h2/h3 headers
- [ ] **Internal Links** - Link to 2-3 related blog posts or services

### Content Checklist
- [ ] **H1 Title** - Matches blog post title (exactly once per page)
- [ ] **H2 Headers** - 2-4 sections with descriptive headers
- [ ] **Paragraphs** - 2-4 sentences each (readable)
- [ ] **Lists** - Use bullet points for step-by-step guides
- [ ] **Call-to-Action** - Link to relevant service pages

### Technical Checklist
- [ ] **Status** - Set to "Published"
- [ ] **Publish Date** - Set to today (auto-filled)
- [ ] **Featured Image Uploaded** - Not broken link
- [ ] **Preview in Admin** - Check formatting, images, links

## ❓ FAQ - For Content Team

**Q: Do I need to change anything when creating posts?**  
A: Just write better meta descriptions and ensure your featured images are 1200x630px. Everything else is automatic!

**Q: Why does meta description matter?**  
A: Google shows it in search results. If it's too long, Google truncates it → users don't see key info → they click less.

**Q: What's the ideal blog post length?**  
A: 800-1200 words minimum. Longer posts (1500-2000 words) rank better if high quality.

**Q: Should I optimize old posts?**  
A: Yes! Update 10-15 top posts per month:
1. Improve meta description (if too long)
2. Add internal links to new content
3. Update any outdated information
4. Ensure featured image is high quality

**Q: How often should I publish?**  
A: 2-4 posts/month is ideal. Quality > quantity.

**Q: What content performs best?**  
A: "How-to" and "Step-by-step" guides (like "FDA Registration: 10 Steps").
- Blog filter showing these perform 40% better
- Target keywords: "Hướng dẫn", "Bước", "Quy trình", "Cách"
